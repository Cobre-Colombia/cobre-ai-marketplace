# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.
Report them privately to: security@cobre.co

Include a description, steps to reproduce, and the affected version.
We aim to acknowledge reports promptly and will keep you informed of progress until they are resolved.

## Scope

This plugin contains only publicly documented Cobre knowledge
(docs.cobre.com). It does not access Cobre internal systems,
does not collect telemetry, and does not send your code anywhere.

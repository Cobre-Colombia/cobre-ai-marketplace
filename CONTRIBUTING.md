# Contributing

## Content rule

Only content already published on docs.cobre.com may be added to this plugin.
Do not include internal URLs, customer identifiers, credentials, staging
endpoints, or internal comments.

## How to contribute

1. Open an issue describing the change.
2. Fork the repo and open a pull request.
3. All changes are reviewed by the maintainers before merging.

## Security

Never commit secrets. See SECURITY.md to report vulnerabilities.
